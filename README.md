# Индивидуальный проект по дисциплине «Базы данных»

## Описание проекта

Проект представляет собой базу данных **«Книжный магазин»**, разработанную в SQLite. 
База данных содержит информацию о книгах, авторах, издателях, категориях, покупателях и заказах.

## Структура проекта

```
IndividualProject_Databases/
├── README.md                  # Описание проекта
├── sql/
│   ├── 01_create_tables.sql    # Создание таблиц
│   ├── 02_insert_data.sql      # Заполнение таблиц данными
│   └── 03_queries.sql          # SQL-запросы (a-m)
└── screenshots/
    ├── query_a.png             # Скриншоты выполнения запросов
    ├── query_b.png
    ├── ...
    └── query_m.png
```

## Структура базы данных

### Справочные таблицы (≥5 строк):

| Таблица        | Описание                  | Кол-во строк |
|----------------|---------------------------|--------------|
| Publishers     | Издатели                  | 6            |
| Authors        | Авторы                    | 8            |
| Categories     | Категории книг            | 6            |

### Операционные таблицы (≥20 строк):

| Таблица        | Описание                  | Кол-во строк |
|----------------|---------------------------|--------------|
| Books          | Книги                     | 24           |
| Customers      | Покупатели                | 22           |
| Orders         | Заказы                    | 24           |

## Схема связей

```
Publishers (1) ──< (M) Books (M) >── (1) Authors
                      |
                      └──> (1) Categories
                      
Customers (1) ──< (M) Orders (M) >── (1) Books
```

## Запросы

В файле `03_queries.sql` реализованы все 13 запросов (a-m):

- **a)** Выбор всех данных по двум полям
- **b)** Выбор неповторяющихся данных по одному полю
- **c)** GROUP BY + HAVING с заголовками колонок
- **d)** DISTINCT + SUM с осмысленным заголовком
- **e)** Выбор нескольких полей, сортировка по убыванию
- **f)** Добавление вычисляемого поля (арифметическое выражение)
- **g)** SUM + условие BETWEEN
- **h)** AVG + условие WHERE
- **i)** Вычисляемое поле + сложная сортировка (3 поля)
- **j)** Условие LIKE
- **k)** Условие + сортировка + константное поле
- **l)** Агрегатные функции MIN и MAX
- **m)** Сложное условие (AND, OR) + сортировка

## Как запустить

1. Установить SQLite (или использовать DB Browser for SQLite)
2. Выполнить скрипты по порядку:
   ```bash
   sqlite3 bookstore.db < sql/01_create_tables.sql
   sqlite3 bookstore.db < sql/02_insert_data.sql
   sqlite3 bookstore.db < sql/03_queries.sql
   ```
3. Или открыть в DB Browser for SQLite и выполнить скрипты вручную
